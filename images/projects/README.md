# Project photos

Drop each photo here with the file name below and it will appear on the site automatically.
Until a file is added, the page shows a striped placeholder with the expected path.

The easiest way to get the originals: in Notion, open each project page, right-click each image, and choose **Download**.
Or use **••• → Export → Markdown & CSV** (include subpages) to get them all at once.

The "Notion image" column lists images in the order they appear on each Notion page.
